fallout scans a project, finds what breaks with a change, and hands it off to IBM Bob 2.0 to complete the review.

WHAT IT DOES

↳What it analyses

Exports, functions, fields and routes that changed between one commit and another.

 ↳What it finds

Other files still using the old signatures, outdated documentation, untested code.

 ↳What Bob does

Reads the architecture, splits the work across three roles, and proposes the fix.

HOW TO USE

  1. 01

    Install dependencies

    npm install
  2. 02

    Install Bob modes (once — restart Bob after)

    node bin/guardian.mjs install-modes
  3. 03

    Analyse a single project

    node bin/guardian.mjs analyze --repo "C:\path\to\your-project"

    Options: --base <branch>  |  --working  |  --last <N>  |  --run-tests  |  --json

  4. 04

    Scan all repos inside a folder

    node bin/guardian.mjs scan "C:\path\to\your-projects-folder"

    Options: --depth 3 (default 2)  |  --run-tests

  5. 05

    Generate the Bob prompt and copy it to the clipboard

    node bin/guardian.mjs prompt --repo "C:\path\to\your-project" --copy
  6. 06

    Hand off to Bob 2.0

    Open the project in Bob → select mode 🛡️ PR Guardian (Orchestrator) → paste the message → approve the 3 parallel subagents.
